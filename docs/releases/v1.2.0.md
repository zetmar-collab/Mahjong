# Mahjong Solitaire 1.2.0 — zmiany

7 listopada 2026. Wydanie lokalne po audycie kodu.

## Poprawki

Naprawiono siedem potwierdzonych usterek: nieograniczony czas zapisu, nadpisywanie postępu przez drugą instancję, klawisz H w nazwie gracza, narastające subskrypcje ekranu, godziny ponad dobę, ignorowany budżet solvera i datę ukończenia. Potwierdzenie zastąpienia partii jest teraz rzeczywistym dialogiem modalnym.

## Nowe możliwości

- Cofnij / Ctrl+Z, z zachowaniem czasu i liczników pomocy. Przetasowanie stanowi granicę cofania; zakończony wynik pozostaje niezmienny.
- Automatyczny zapis zwycięstwa oraz jednorazowe dopisanie nazwy gracza później.
- Filtrowana i wirtualizowana historia, sortowanie oraz rekordy osobno według układu, zestawu i pomocy.
- Kopie .mahjongbackup: partia, historia, ustawienia i własne tło; walidacja sum, ścieżek, rozmiarów i zawartości przed importem. Poprzednie pliki pozostają w Backups. Import zastępuje pliki obecne w kopii, pozostałych nie zmienia.
- Zoom 100–300% z paskami przewijania i powrotem do dopasowania.
- Trzy interaktywne ćwiczenia PL/EN.
- Dzienne wyzwanie offline według lokalnej daty.
- Kody MJ1 zawierające cały początkowy rozkład i rozwiązanie kontrolne, bez danych gracza.

Dodano limity plików i historii, uporządkowany zapis w tle, aktualizowanie samego zaznaczenia bez przebudowy planszy, ograniczony log diagnostyczny i testy WPF do konfiguracji CI. Nie dodano bazy SQL, usług sieciowych ani zależności NuGet.

Starsze dane formatu 1 są nadal odczytywane. Nie wykonano migracji ani ręcznej zmiany danych gracza. Wersja 1.1 nie respektuje nowej blokady — należy ją zamknąć przed uruchomieniem 1.2.

## Walidacja i dostarczenie

Szczegóły: v1.2.0-validation.md oraz TEST_RESULTS.md w katalogu projektu. Gotowe pliki lokalne: artifacts/installer/Mahjong-Solitaire-1.2.0-Setup-x64.exe i artifacts/Mahjong-win-x64.zip. Publiczne wydanie GitHub nadal ma numer 1.1.0; audyt i implementacja nie wysyłały zmian do GitHub.

## English

Version 1.2 fixes all seven confirmed audit findings and adds undo, automatic victory recording, filtered and virtualized best times, validated backups, board zoom, three interactive tutorials, offline daily challenges and full MJ1 deal codes. Existing saves remain readable. The new setup and portable ZIP are local build artifacts. Public GitHub downloads remain at 1.1.0.
