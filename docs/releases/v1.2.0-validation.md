## Ograniczenia

Nie przeprowadzono osobnej próby Windows 10, fizycznych przejść między monitorami DPI, odsłuchu audio ani pełnego testu czytnika ekranu. Okna wyboru plików i systemowy schowek wymagają ręcznego sprawdzenia; logika kopii i kodów została sprawdzona automatycznie. EXE i setup nie mają podpisu certyfikatem wydawcy. Nie deklarujemy wykonania zdalnego CI dla tych zmian — konfigurację dodano, testy wykonano lokalnie.

Nie opublikowano zmian na GitHubie. Poprzednie wydanie 1.1.0 pozostaje dostępne publicznie.
