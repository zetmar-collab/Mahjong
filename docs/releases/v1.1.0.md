# Mahjong Solitaire 1.1.0 — Windows x64

## Pobieranie

- **Mahjong-Solitaire-1.1.0-Setup-x64.exe** — instalator z grą, wszystkimi zasobami i .NET. Kreator PL/EN, skróty Start i opcjonalny pulpit, deinstalator. Instalacja dla bieżącego użytkownika, bez administratora i internetu.
- **Mahjong-win-x64.zip** — wersja przenośna; rozpakuj cały folder i uruchom Mahjong.exe.
- Pliki **.sha256** zawierają sumy kontrolne obu pakietów.
- **USER_GUIDE.txt** — instrukcja PL/EN.

## Zawartość gry

Sześć układów, trzy zestawy płytek, poprawne blokady i rozwiązywalne początki, podpowiedzi, jedno przetasowanie na partię, zapis i wznowienie. Polski i angielski, pięć teł i własny obraz z pliku, trzy motywy, lokalne dźwięki, obsługa klawiaturą. Po zwycięstwie gratulacje, konfetti i opcja zapisania wyniku do lokalnej historii.

Instalacja, aktualizacja i odinstalowanie zachowują dane gracza w %LOCALAPPDATA%/QuietMahjong.

## Weryfikacja i ograniczenia

- Silnik: 20 zestawów testów, 378 odtworzonych pełnych rozwiązań.
- Aplikacja: 459 kontroli WPF.
- Instalator: 1696 kontroli instalacji PL, aktualizacji EN, plików, skrótów i odinstalowania.
- Testowano Windows 11 x64. Nie wykonano oddzielnego testu na Windows 10 ani fizycznej próby przełączania DPI między monitorami.
- Instalator i gra nie mają podpisu Authenticode.

Kod źródłowy oraz oryginalne zasoby: MIT. Informacje o .NET i Inno Setup: THIRD_PARTY_NOTICES.md w repozytorium i licencje w pakietach.

## English

Download **Setup-x64.exe** for a complete offline installation, or extract the entire **portable ZIP**. No separate .NET installation is needed. The installer is available in Polish and English; switch the game language with PL / EN. The release is unsigned and was tested on Windows 11 x64. Uninstalling preserves local saves, results, settings and the custom background.
