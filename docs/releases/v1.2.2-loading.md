# Mahjong Solitaire 1.2.2 — ładowanie planszy

12 listopada 2026, Windows x64, SDK .NET 10.0.401.

## Przyczyna i poprawka

Nowa partia przełączała ekran na planszę jeszcze przy `Busy = true`. Widok rysował płytki i blokującą nakładkę ładowania. Po zakończeniu operacji optymalizacja `DrawBoard` rozpoznawała ten sam identyfikator partii, zoom i symbole, więc aktualizowała tylko zaznaczenia. Nakładka pozostawała nad przyciskami.

Pamięć ostatniego renderowania uwzględnia teraz także stan zajętości. Zmiana tego stanu wymusza przebudowę widoku i usunięcie nakładki.

## Weryfikacja

- Test regresji uruchomiony przed poprawką zakończył się błędem `Loading overlay is removed after new game glade`, potwierdzając odtworzenie usterki.
- Po poprawce: 561 kontroli WPF, bez błędów. Nowe kontrole obejmują zakończenie zajętości, brak tekstu nakładki, trafienie wskaźnika w przycisk płytki oraz zaznaczenie przez zdarzenie kliknięcia. Sprawdzono sześć układów, ponowną grę, wyzwanie dnia, kod partii i przetasowanie.
- 31 zestawów silnika i danych, bez błędów; 378 pełnych rozwiązań odtworzonych w podstawowym liczniku.
- Kompilacja Release: bez błędów i ostrzeżeń.
- Zbudowano instalator 1.2.2 z 417 plikami w manifeście SHA-256 oraz przenośny ZIP. Nie uruchamiano testu instalacji i odinstalowania, ponieważ na komputerze jest już zarejestrowana instalacja gracza.

Nie zmieniono formatu zapisu. Testy WPF używają osobnego katalogu SmokeData. Instalator i ZIP zawierają runtime .NET. Pliki wykonywalne pozostają bez podpisu cyfrowego. Nie wykonano osobnego testu na Windows 10 ani fizycznego testu myszy na innym komputerze.
