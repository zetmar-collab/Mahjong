# Mahjong Solitaire 1.2.1 — Windows

Gra offline dla Windows x64. Instalator zawiera wszystkie zasoby i .NET; nie wymaga administratora ani połączenia z internetem.

## Nowości od wersji 1.1

- Poprawiono siedem usterek audytu: walidację czasu, ochronę zapisu przed drugą instancją, wpisywanie nazwy, subskrypcje widoku, czas ponad dobę, limit solvera i datę ukończenia.
- Cofanie ruchów / Ctrl+Z, automatyczny zapis zwycięstwa i opcjonalna nazwa gracza.
- Rekordy i filtry historii, eksport/import danych z zachowaniem poprzedniej kopii.
- Powiększanie planszy, trzy interaktywne ćwiczenia, wyzwanie dnia offline i kody całego początkowego rozkładu MJ1.
- Poprawiony wygląd menu, ustawień i wyników, spójne kontrolki trzech motywów, kontrast i fokus klawiatury, przyciski nowej gry zawsze widoczne.

## English

Offline Mahjong Solitaire for Windows x64. The installer bundles the runtime and assets and requires no administrator account. This release includes undo, automatic victory recording, filtered best times, backups, zoom, tutorials, daily challenges, complete deal codes and an improved three-theme interface. Existing saves remain readable.

Download the Setup EXE, or extract the entire portable ZIP and run Mahjong.exe. Validation: 31 engine suites, 521 WPF checks and 1693 installer checks passed. Close version 1.1 before upgrading. This release is unsigned and was tested on Windows 11 x64; Windows 10 and physical multi-monitor/audio tests remain unverified.
